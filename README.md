# Endometriose-Schweiz-
Dieses Repository beschäftigt sich mit Endometriose in der Schweiz. Es behandelt Symptome, Diagnostik, Behandlungsmöglichkeiten sowie die Herausforderungen im Schweizer Gesundheitssystem und soll das Bewusstsein für diese Erkrankung schärfen.
